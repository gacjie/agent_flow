# UI/UX 设计速查

## 【工具选择】

| 目的 | 使用工具 | 使用时机 | 不要用于 |
|------|---------|---------|---------|
| 了解项目前端结构 | `list_files` | 首次接触或不确定路径时 | 已知路径后重复列出 |
| 读取现有样式和布局 | `read_files` | 继承已有视觉体系 | 大范围内容搜索 |
| 搜索参考站点 | `web_searches` | 新建项目提取可量化参数 | 已有项目（直接读现有代码）|
| 查看参考页面 | `browser_action` | 截图和 DOM 分析 | 首次项目结构探索 |

## 【常见判断】

| 遇到情况 | 正确做法 | 错误做法 |
|---------|---------|---------|
| 用户描述模糊（如"简洁"） | 搜索参考站点提取可量化参数 | 凭感觉设计 |
| 已有项目无 CSS 变量 | 从现有硬编码值中提取，建立变量体系 | 推翻重写 |
| 用户需求与参考站点冲突 | 用户需求优先，标注冲突点 | 采用参考覆盖用户需求 |
| 参考站点包含具体交互/数据 | 只提取视觉参数，交互和数据以项目事实为准 | 当作项目需求或契约 |
| 组件太多一次写不完 | 先公共组件，再按模块优先级逐个产出 | 全部产出粗糙骨架 |
| 服务端模板项目 | 设计基础模板继承结构和页面片段 | 只给 SPA 组件结构 |
| 页面域/应用壳包含多个页面 | 先产出壳层和局部通用组件，再逐业务页面产出模板 | 合成一个大模板 |
| 组件被多个业务页面复用 | 放入公共或局部通用模板 | 复制到每个业务页面 |
| 列表/表单/异步页面 | 设计加载、空、错误、权限失败、禁用、焦点和校验状态 | 只设计理想成功态 |
| 涉及安全体验 | 只设计用户可见提示和状态 | 设计后端认证/CSRF/XSS 模块 |
| MVC 多应用示例 | 全局规则→admin 壳层→登录/仪表盘/设置等页面模板 | 只产出 ui-patterns-admin |

## 【前端层级识别】

| 层级 | 典型内容 | 产出 |
|------|---------|------|
| 全局前端底座 | CSS 变量、主题、基础布局规则、请求封装状态样式 | `docs/frontend-conventions.md` 或 `ui-patterns-common` |
| 页面域/应用壳 | 后台壳、门户壳、工作台壳、导航、侧栏、面包屑、权限状态 | `ui-patterns-{domain}-shell` |
| 域内通用组件 | 表格、筛选、分页、表单、弹窗、卡片、空状态 | `ui-patterns-{domain}-common` |
| 业务页面/交互模块 | 登录页、仪表盘、系统设置、权限管理、报表导出 | `ui-patterns-{domain}-{feature}` |
