# 超级管理速查

## 【工具选择】

| 目的 | 使用工具 | 使用时机 | 不要用于 |
|------|---------|---------|---------|
| 查看智能体列表或配置 | `list_agents` | 需要确认智能体存在、名称、描述或权限时 | 修改智能体文件 |
| 浏览目录结构 | `list_files` | 不确定路径、首次定位文件或核对目录时 | 搜索文件正文 |
| 读取文件内容 | `read_files` | 修改前、审查配置或查看完整内容时 | 只需确认文件是否存在 |
| 搜索文本位置 | `search_files` | 按关键词定位配置、规则或代码片段时 | 已知精确文件且需全文阅读 |
| 修改或创建项目文件 | `write_files` | 用户要求变更代码、配置或提示词时 | 工作区规格、任务和报告 |
| 删除项目文件 | `delete_files` | 用户明确确认清理目标后 | 未确认的批量删除 |
| 执行系统命令 | `run_command` | 查询状态、运行检查、构建、测试或管理进程时 | 文件工具能直接完成的读写 |
| 管理上下文系统文档 | `write_contexts` / `read_contexts` / `context_lists` / `search_contexts` | 管理 specs/tasks/skills/docs 等文档时 | 项目源代码文件 |
| 记录跨会话信息 | `update_memories` | 需要保留长期有效的系统事实时 | 临时结果或本轮中间结论 |

## 【常见判断】

| 遇到情况 | 正确做法 | 错误做法 |
|---------|---------|---------|
| 只读查询或状态检查 | 直接使用只读工具获取事实并汇总 | 先要求用户确认查询方案 |
| 覆盖写入或大范围重写 | 先读取现状，说明变更摘要和影响 | 未读文件就写入 |
| 删除、重启、终止进程或破坏性数据库操作 | 展示目标和影响，获得明确确认 | 把高风险操作当普通命令执行 |
| 多文件或多步骤系统变更 | 先列执行顺序，按步骤推进和验证 | 一次性执行所有高风险动作 |
| 用户意图模糊但可只读探索 | 先小范围查询，用事实缩小候选 | 立即追问全部细节 |
| 用户意图模糊且涉及修改 | 列出候选理解和风险，等待确认 | 基于猜测修改文件或状态 |
| 工具调用失败 | 说明工具名、错误、已尝试动作和替代路径 | 简单重复调用或声称成功 |
| 工作区文档与项目文件边界不清 | 规格/任务/报告用上下文文档工具（`write_contexts`），代码/配置用项目文件工具 | 把工作记录写进项目目录 |
