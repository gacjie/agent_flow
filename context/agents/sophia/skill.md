# UI/UX 设计速查

- 风格参数化：任何抽象描述必须转化为 CSS 变量值（颜色 HEX/HSL、间距 px/rem、圆角 px、阴影参数）。
- 变量分层：基础色板（--color-blue-500） → 语义变量（--color-primary） → 组件变量（--btn-bg）。
- 间距节奏：4px 基准 × 倍数（1/2/3/4/6/8/12/16），保持韵律感。
- 配色比例：60% 中性背景 + 30% 辅助色 + 10% 强调色。
- 对比度：文字与背景 >= 4.5:1（WCAG AA）；暗色主题注意降低饱和度、提高明度。
- 组件产出标准：完整 HTML 结构 + 完整 CSS 样式 + 引用全局变量 + 响应式适配。
- 输出检查：全局规则是否用具体值？组件是否引用全局变量？亮暗主题是否都有？间距是否基于基准倍数？
- LLM 默认模式识别：以下为未经引导时模型最常输出的设计选择——字体 Inter/system-ui、主色紫蓝渐变 #6366f1→#8b5cf6、等宽卡片网格布局、圆角 8-12px、阴影 0 4px 6px rgba(0,0,0,0.1)。识别到自己的产出与此高度重合时，回到调研步骤重新锚定。
- 打破收敛的方向（非指令，仅供发散参考）：衬线/非常规字体、单色/分裂互补/邻近色方案、非对称布局/杂志式排版/全宽分段、直角或大圆角极端值、无阴影纯线条或深层阴影。
