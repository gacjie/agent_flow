# 前端速查

## 【工具选择】

| 目的 | 使用工具 | 使用时机 | 不要用于 |
|------|---------|---------|---------|
| 了解前端目录全貌 | `list_files` | 首次接触项目，找模板/CSS/JS 目录 | 已知路径后重复列出 |
| 快速了解文件结构 | `analysis_files` | 文件 >100 行只需知道有哪些选择器/函数 | 需要复制代码片段时 |
| 定位已有组件或样式 | `search_files` | 搜索 class 名、CSS 变量名、函数名 | 关键词太泛（如 "div"） |
| 读取实现细节 | `read_files` | analysis 后确认需要具体代码 | 首次探索（先用 analysis） |
| 验证页面渲染和交互 | `browser_action` | 页面开发完成后验证效果 | 纯样式变量查询 |
| 搜索已有实现 | `search_files` | 新建 JS 函数或 CSS 组件前 | 已确认不存在同功能实现后 |

**顺序原则**：list/analysis/search/read → run/browser_action。

## 【常见判断】

| 遇到情况 | 正确做法 | 错误做法 |
|---------|---------|---------|
| 新增页面不确定布局 | 读取主模板和同类页面→按相同结构编写 | 自行设计布局 |
| 样式与已有组件冲突 | 用更具体选择器或 BEM 命名隔离 | 修改全局 CSS 变量 |
| 模板继承关系不清楚 | 读取 layout 目录→确认 define/block 结构 | 跳过布局直接写内容 |
| 响应式布局需求 | 查找项目已有断点→按已有规则适配 | 新增任意断点 |
| 页面渲染为空白 | 检查模板路径、继承关系、数据传递 | 重写整个模板 |
| 静态资源 404 | 确认文件存在→检查引用路径 | 复制资源到多个目录 |
| JS 交互无响应 | 检查事件绑定选择器和 DOM 加载时机 | 添加 setTimeout 猜测时机 |
| API 请求失败或 pending | 核对路由→检查 URL/方法/参数/CSRF/超时 | 只看控制台不查网络 |
| API 请求返回成功响应 | 同时检查 HTTP 状态、业务状态、响应结构和异常提示 | 只因 Promise resolved 就当成功 |
| 渲染外部内容或工具输出 | 使用转义、DOM API、来源白名单或安全封装 | 直接 innerHTML 或开放跳转 |
| 页面有异步数据或列表 | 实现加载、空、错误和重试/诊断状态 | 只实现有数据成功态 |
| 页面有表单或权限状态 | 覆盖校验、禁用、焦点、权限失败和错误提示 | 只提交正常值 |
| 动态字段名、选择器或 URL | 使用转义、白名单或 DOM API 构造 | 字符串拼接后直接 querySelector/跳转 |
| resize/input/scroll 高频事件 | 按项目模式防抖/节流并验证边界 | 每次事件都重排或请求 |
| 浏览器验证 | 页面结构→控制台→交互→网络→截图 | 只打开页面不检查细节 |
| 多主题适配 | 使用 CSS 变量→两个主题下都验证 | 只在当前主题验证 |
