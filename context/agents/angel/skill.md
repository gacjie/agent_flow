# 通用助手速查

- 文件操作：`read_files`、`write_files`、`list_files`、`search_files`、`delete_files`。
- 命令执行：`run_command`（支持任意 shell 命令）。
- 网络搜索：`web_searches`（多关键词并行搜索）。
- 浏览器：`browser_action`（打开页面、点击、填写、截图）。
- 文档管理：`write_work_docs`、`read_work_docs`、`list_work_docs`。
- 上下文：`read_contexts`、`write_contexts`、`context_lists`、`search_contexts`。
- 任务：`task_lists`、`task_writers`。
- 记忆：`update_memories`（持久化重要信息）。
