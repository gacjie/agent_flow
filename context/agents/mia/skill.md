# 前端测试速查

## 【工具选择】

| 目的 | 使用工具 | 使用时机 | 不要用于 |
|------|---------|---------|---------|
| 查看任务要求 | `task_lists` | 确认页面、验收标准、任务文档 | 创建或修改任务 |
| 了解前端结构 | `list_files` | 找路由、模板、页面、静态资源、测试目录 | 读取文件内容 |
| 快速定位入口 | `search_files` | 搜索 route、template、page、component、form 等关键词 | 浏览目录结构 |
| 分析代码逻辑 | `analysis_files` | 理解页面、组件、请求封装和交互调用关系 | 需要完整源码细节时 |
| 读取完整代码 | `read_files` | 需要查看路由、页面、样式、测试样例 | 只需了解文件结构时 |
| 编写测试脚本 | `write_files` | 新增或调整 E2E、链接检查、验证脚本 | 修改业务代码 |
| 运行命令 | `run_command` | 启动前端服务、执行测试、批量检查链接/API | 修改文件内容 |
| 验证页面 | `browser_action` | 真实访问、交互、响应式、控制台、截屏 | 纯后端接口测试 |

## 【常见判断】

| 遇到情况 | 正确做法 | 错误做法 |
|---------|---------|---------|
| 启动命令不明确 | 优先按 AGENTS.md 服务管理章节命令启动；不可用时从 README/脚本/配置推断 | 直接套默认命令 |
| 页面 URL 不明确 | 从路由、模板、菜单和入口结构推断并标注 | 随意编造路径 |
| 服务端渲染模板 | 按用户可见页面测试渲染、资源和表单 | 当作纯后端跳过 |
| 需要证明前端可用 | 验证页面、资源、交互、接口调用、响应式和截图证据 | 只看 HTTP 200 |
| API 返回异常 | 请求封装/参数/状态处理标注 `[Frontend]`；后端响应错误、契约违背、权限/数据根因标注 `[Backend]` | 一律归为前端或执行后端专项测试 |
| API Promise resolved | 继续检查 HTTP 状态、业务状态、响应结构和错误提示 | 当作请求成功 |
| 响应式异常 | 截图记录视口尺寸、页面位置和遮挡/溢出表现 | 只写“样式有问题” |
| 控制台报错 | 记录错误文本、页面 URL、触发动作和堆栈 | 忽略非阻塞错误 |
| 表单验证 | 覆盖空值、超长、特殊字符、重复提交和错误提示 | 只提交正常值 |
| 弹窗、菜单、分页或折叠 | 验证键盘焦点、ARIA/语义状态、展开/关闭和响应式可读性 | 只用鼠标点开一次 |
| 动态字段名、selector 或 URL | 输入特殊字符验证转义、白名单和错误态 | 只测普通字母数字 |
| 链接检测 | 提取 DOM 链接和静态资源，区分外链、锚点、应用内路由 | 只肉眼点几个链接 |
| 截屏范围 | 关键页面和三类视口都留证 | 只截首页 |
| 浏览器不可用 | 明确降级方式和未覆盖风险 | 声称已完成浏览器验证 |
