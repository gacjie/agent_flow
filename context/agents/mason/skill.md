# 后端开发速查

## 【工具选择】

| 目的 | 使用工具 | 使用时机 | 不要用于 |
|------|---------|---------|---------|
| 确认目录结构 | `list_files` | 首次接触或不确定路径时 | 已知路径后重复列出 |
| 快速了解文件结构 | `analysis_files` | 文件 >100 行只需知道函数/类/类型/导出 | 需要复制代码片段时 |
| 定位函数或模式 | `search_files` | 知道关键词但不知路径 | 关键词太泛或替代读取目标文件 |
| 读取实现细节 | `read_files` | 已知目标文件或 analysis 后需要具体代码 | 首次探索大型未知文件 |
| 读取语言技能 | `read_contexts` | 识别语言后读取 `skills/backend-*.md` | 读取项目代码或 agent 配置 |
| 查找技能路径 | `context_lists` / `search_contexts` | 不确定技能名或需要语言技能摘要时 | 替代任务和代码勘察 |
| 验证构建/启动/测试 | `run_command` | 验证阶段 | 探索性查看文件内容 |

## 【语言技能选择】

| 线索 | 读取技能 |
|------|---------|
| `[Backend:Go]`、`go.mod`、`.go` 目标文件 | `skills/backend-go.md` |
| `[Backend:Python]`、`pyproject.toml`、`requirements.txt`、`.py` 目标文件 | `skills/backend-python.md` |
| `[Backend:PHP]`、`composer.json`、`.php` 目标文件 | `skills/backend-php.md` |
| `[Backend:Node]`、`package.json` 后端入口、`.js/.ts` 服务端文件 | `skills/backend-node.md` |
| 其他语言或无法判断 | `skills/backend-generic.md` |

## 【常见判断】

| 遇到情况 | 正确做法 | 错误做法 |
|---------|---------|---------|
| 任务要求新增接口 | 先搜同类接口实现，再按项目模式编写 | 从零设计接口风格 |
| `[Backend]` 无语言标签 | 扫描配置和目标文件识别语言，再读对应技能 | 默认选择熟悉语言 |
| 多语言仓库 | 按目标文件、入口和任务描述确定本次语言 | 按仓库最大语言处理所有任务 |
| 任务涉及模板视图数据 | 处理后端查询、数据组装和模板变量注入，模板结构/样式/交互交给 emma | 顺手重写前端布局 |
| 任务未写安全要求但有外部输入/数据写入 | 落实校验、参数化、权限或事务等适用项 | 只做快乐路径 |
| 任务使用模型/工具输出 | 校验来源、格式、权限和敏感信息后落地 | 直接执行或保存输出 |
| 发现设计缺少明显后端安全边界 | 保守处理可确定部分并报告缺口 | 自行扩成完整安全重构 |
| 不确定包管理器或测试命令 | 查 lock 文件、脚本、README、CI 配置 | 固定使用常见命令 |
| 非本次变更引入的错误 | 记录但不修复，在结果中说明 | 修复所有看到的错误 |
| 不确定字段命名 | 搜索项目中同类字段命名惯例 | 用个人习惯命名 |
