# 审查速查

## 【严重度分级】

- 严重：可导致数据泄露、权限绕过、远程利用、资金或核心业务错误。
- 警告：潜在安全、稳定或一致性风险，建议发布前修复。
- 建议：可维护性、性能或体验优化，不阻塞交付。

## 【高风险模式】

- 用户输入进入 SQL、命令、路径、模板或 HTML。
- 外部内容、模型输出或工具结果进入命令、文件、模板、权限判断或持久化。
- 敏感信息出现在代码、日志、响应或序列化结构。
- 新接口缺少权限、校验、错误处理或分页。
- 前后端字段、状态值、路径或响应结构不一致。
- 路由、菜单入口、静态资源、启动配置或迁移依赖缺失。
- 框架路由自动注册暴露私有方法。
- RBAC 权限表存在但无请求拦截中间件。
- 模板 CSS class 名在项目 CSS 中无定义。
- 权限、会话、禁用状态或角色变更后缺少级联失效。
- 查询参数、表单、JSON 或配置值来源混用导致覆盖。
- 字段名、关联 ID、长度/数量、文件路径或跳转 URL 缺少白名单。
- 多个低级问题可组成提权、数据破坏、DoS 或绕过审计攻击链。
- 测试只覆盖成功路径、缺少断言、共用生产/开发数据或未覆盖权限边界。

## 【常见判断】

| 遇到情况 | 正确做法 | 错误做法 |
|---------|---------|---------|
| 不确定是否为问题 | 标注"疑似"或降低严重度，说明不确定原因 | 直接标严重或忽略 |
| 同一模式多处出现 | 详述一处，其余列出位置 | 每处完整重复描述 |
| 涉及架构级问题 | 说明跨模块影响，按影响定级 | 因单点无害直接降为建议 |
| 涉及运行接通 | 检查启动、路由、入口、资源和核心流程 | 只看单文件逻辑 |
| 涉及外部内容/工具输出 | 追踪输入源→权限边界→验证点→危险调用 | 默认可信或只看表面功能 |
| 涉及权限或状态生命周期 | 追踪登录/变更/禁用/撤销/登出全链路 | 只检查当前接口权限判断 |
| 多个中低风险相邻 | 尝试组合攻击链并重新定级 | 每项孤立标建议 |
| 审查测试代码 | 检查断言、隔离、失败路径和权限边界覆盖 | 只看测试是否能运行 |
| 风格 vs 功能问题 | 风格标建议，功能至少标警告 | 混为一谈 |
| 安全问题定级 | 给出证据链后按影响定级 | 所有安全问题一律严重 |

## 【工具选择】

| 目的 | 使用工具 | 使用时机 | 不要用于 |
|------|---------|---------|---------|
| 了解项目全貌 | `list_files` | 先确认路径再读文件 | 读取文件内容 |
| 快速了解文件结构 | `analysis_files` | 查看函数/类型列表 | 需要审查完整逻辑时 |
| 定位危险模式 | `search_files` | 搜索 SQL 拼接、eval、innerHTML 等 | 浏览目录结构 |
| 审查完整实现 | `read_files` | 需要完整逻辑流 | 只需函数签名时 |
| 验证前端问题 | `browser_action` | 需页面证据 | 纯后端审查 |
| 查看任务要求 | `task_lists` | 确认审查范围 | 创建或修改任务 |
