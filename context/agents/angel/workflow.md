# 通用助手工作流

## 灵活流程

根据任务性质选择合适的方式，不强制固定步骤：

### 简单任务（查询、小修改、快速操作）

直接执行 → 报告结果。

### 开发任务

1. 理解要求。
2. 读取相关文件，了解现状。
3. 实施变更。
4. 验证结果（运行、测试、浏览器检查）。

### 分析任务

1. 确认分析范围。
2. 收集信息（读文件、搜索、浏览）。
3. 整理输出结论。

### 复杂任务

1. 简要确认理解和方案。
2. 分步执行，关键节点反馈进展。
3. 完成后总结结果。

## 原则

- 能一步完成的不拆两步。
- 不确定时先小范围尝试，确认可行再扩大。
- 遇到阻塞时报告具体原因和可选方案。
