# 后端综合安全技能

> 后端安全规范全面清单。设计师读取后按项目裁剪产出 docs/backend-security.md——过滤项目不涉及的安全面，将适用项转化为具体技术方案。开发/测试/审查智能体优先使用项目文档，无项目文档时读此技能作为降级。

| 排名 | 名称 | 变化 | 说明 |

| A06 | Insecure Design | — | 不安全的设计（缺少威胁建模） |

## OWASP Agentic Applications 2026

适用于智能体/MCP/工具链/自动执行系统（2025.12 发布）。

| 编号 | 风险 | 关键防护 |
|------|------|---------|
| ASI01 | 目标劫持/提示注入 | 恶意内容篡改决策路径；输入/输出边界过滤，指令与数据隔离 |
| ASI02 | 工具误用 | 不安全工具组合/递归/过度执行；工具白名单 + 执行确认 |
| ASI03 | 身份与权限滥用 | 智能体获得超出必要权限；最小权限 + 分离执行身份 |
| ASI04 | 智能体供应链 | 恶意 MCP 服务器/Agent 卡片；来源验证 + 签名校验 |
| ASI06 | 记忆与上下文投毒 | 污染记忆文件影响后续决策；记忆写入校验 + 审计 |
| ASI07 | 智能体间不安全通信 | 子智能体间无认证/未加密；通信签名 + 权限隔离 |
| ASI08 | 级联故障 | 单点失败传播到整个链路；熔断 + 超时 + 降级 |

## 风险触发项（后端）

| 风险面 | 触发条件 | 关注点 |
|--------|---------|--------|
| 外部输入 | 表单、API、文件、命令参数、URL、第三方回调、模型/工具输出 | 参数来源隔离、字段白名单、长度/数量/深度/耗时限制、注入、非法格式、错误响应 |
| 身份权限 | 登录、会话、角色、所有权、敏感操作 | 认证泄露、客户端高权限字段、授权范围、自操作/横向越权、禁用状态、权限变更后会话失效、暴力破解、时序枚举 |
| 状态变更 | 新增、修改、删除、批量操作、支付、配置变更 | 方法约束、防伪请求(CSRF)、事务、引用完整性、幂等/重复提交、唯一冲突、版本一致性、数据生命周期 |
| 并发/运行暴露 | 多线程/进程、异步、定时任务、网络服务 | 锁、原子写、崩溃恢复、超时、资源上限、频率限制、连接/缓存生命周期、安全传输、审计 |

| 第三方 API | 外部服务对接、OAuth、支付网关 | 鉴权失败、超时/取消、限流、重试幂等、非 JSON 响应、错误码映射、敏感日志过滤 |
| SQL/数据处理 | 报表、导入导出、批量任务、数据清洗 | NULL、重复数据、字段白名单、分页/批处理、索引/全表扫描、事务回滚 |

## 安全检查清单

### 输入验证（8 类注入防护）

| 注入类型 | 攻击方式 | 核心防护 |
|---------|---------|---------|
| SQL 注入 | 拼接用户输入到 SQL 语句 | 参数化查询 `WHERE field = ?`，禁止字符串拼接 |
| XSS | 注入恶意脚本到动态页面 | 自动转义模板引擎，上下文感知编码（HTML/JS/URL/CSS） |
| 命令注入 | 输入传入 os.exec 类函数 | 参数数组传递，白名单验证，禁止 shell 字符串拼接 |
| LDAP 注入 | 操纵 LDAP 查询获取未授权数据 | 转义特殊字符 `()*\`，输入格式校验 |
| 路径遍历 | `../` 访问文件系统任意文件 | 基目录锁定 + realpath 验证在允许范围内 |
| NoSQL 注入 | JSON 操作符注入 MongoDB 等查询 | 强制输入类型 + 过滤 `$` 操作符 |
| 日志注入 | 伪造/篡改日志条目 | 结构化 JSON 日志，数据字段与日志结构分离 |
| 模板注入 | 用户输入作为服务端模板渲染 | 只传数据不传模板，禁止动态模板字符串拼接 |

**核心原则**：进入时验证 → 输出时编码 → 必须保留结构时才做清理

- 所有输入（body/params/headers/query）有类型、长度、范围校验
- 动态 SQL 字段名、排序方向使用白名单校验
- 跳转目标只允许站内路径（防 open redirect）
- 响应头、日志、错误信息拒绝 CRLF 和控制字符

### 认证与会话

**Cookie 三件套**（必设）：HttpOnly（防 XSS 窃取）+ Secure（仅 HTTPS）+ SameSite=Strict/Lax（防 CSRF）

**Token 管理**：JWT 白名单签名算法（防 `alg:none` 绕过）、短有效期 + 定期轮换、浏览器端优先 HttpOnly Cookie 存储（禁用 localStorage）、payload 不放敏感数据（签名 ≠ 加密）

**暴力防护**：认证端点限速（5-10 次/15 分钟）→ 多次失败锁定/验证码 → 多因素认证

- 登录成功后重新生成会话标识（防 session fixation）
- 密码/token 比较使用常量时间函数（防时序攻击）
- 认证失败不泄露账户存在/锁定/状态差异
- 会话在登录/登出/禁用/权限变更时有明确更新或销毁策略
- 密码使用 bcrypt/Argon2（cost >= 10）哈希存储

### 授权与访问控制

| 风险 | 说明 | 防护 |
|------|------|------|
| BOLA | 修改 URL 中 ID 即可访问他人资源 | 每次请求验证资源所有权，数据层 `WHERE owner_id = ?` |
| BFLA | 普通用户可调用管理员 API | 接口级权限校验中间件，默认拒绝 |
| IDOR | 暴露内部对象引用无授权检查 | UUID 替代自增 ID 作为外部标识 |
| 权限提升 | 攻击者获得超出角色的权限 | 最小权限原则，高权限字段不由客户端决定 |

- 权限同时检查数据层约束、服务层判断和入口拦截
- 关键主体保留不变量（如最后管理员不可删除/禁用）
- 权限变更后级联失效会话和缓存

### 加密与数据保护

- 全站强制 HTTPS + HSTS，TLS 1.2+ 禁用弱密码套件
- 密钥/凭据不硬编码，使用环境变量或 KMS，定期轮换
- 随机数使用 crypto/rand（非 math/rand），会话标识至少 128 位熵
- 敏感数据（PII/金融）加密存储，密码字段 `json:"-"` 永不序列化
- 不同环境使用不同密钥，.env 文件在 .gitignore 中

### 文件上传安全

**三重校验**：扩展名白名单 + MIME 类型验证 + 文件头魔数确认真实类型

- UUID 重命名（不保留原文件名），清理路径分隔符和特殊字符
- 存储于 Web 根目录之外或独立存储服务，禁止执行权限
- 严格文件大小限制，读取前检查 Content-Length
- `X-Content-Type-Options: nosniff` 防 MIME 嗅探

### 配置与部署

**安全头**（统一中间件）：`Strict-Transport-Security` / `X-Frame-Options: DENY` / `Content-Security-Policy` / `X-Content-Type-Options: nosniff` / `Referrer-Policy`

**供应链安全**：依赖锁定（go.sum / package-lock.json）+ 定期漏洞扫描 + 来源完整性验证 + 最小化依赖

- 生产密钥缺失拒绝启动，DEBUG 默认关闭，安全机制不被环境变量绕过
- 异常情况下默认拒绝（fail-closed），不因异常跳过安全检查（A10）
- CI/CD 集成 SAST + 依赖扫描，阻止含关键漏洞的依赖部署

### 日志与监控

- 记录安全事件：认证成功/失败、授权失败、输入验证失败、管理操作、配置变更
- 不记录密码/Token/PII，日志含时间戳/用户/IP/操作/结果
- 请求体/日志/缓存/会话/临时数据有大小/保留期/轮转策略
- 异常行为告警（访问突增/大量失败登录），日志不可篡改

### 状态变更与并发

- 状态变更入口校验请求方法（禁止 GET 触发危险操作）
- CSRF 或等价防伪请求保护，登出不豁免 CSRF
- 唯一性/余额/权限变更依赖数据库约束、事务、锁或幂等键
- 先查后写有唯一约束和冲突处理，超时和连接上限配置到位
- 自动执行命令/写文件/调用工具前有白名单或权限边界

## 审查高风险模式（后端）

以下模式在审查中应重点关注，多个中低风险可组合成更高风险攻击链：

- 用户输入进入 SQL、命令、路径、模板或 HTML
- 外部内容、模型输出或工具结果进入命令、文件、权限判断或持久化
- 敏感信息出现在代码、日志、响应或序列化结构
- 新接口缺少权限、校验、错误处理或分页
- 第三方 API 只处理成功响应，缺少失败路径覆盖
- SQL 只参数化值，缺少字段白名单、NULL/重复、分页评估
- RBAC 权限表存在但无请求拦截中间件
- 认证失败存在可枚举响应或时序差异
- 响应头、跳转 URL、日志或错误信息拼接用户输入
- 权限/会话/禁用状态变更后缺少级联失效
- 客户端可控字段影响高权限状态或敏感配置
- 请求体/文件/缓存/连接/日志无上限或无生命周期
- 先查重后写入无唯一约束、事务或冲突处理
- 搜索/分页/批量处理存在 N+1、O(n^2) 或无分页退化
- 状态变更入口缺少方法约束或防伪请求
- 多个低级问题可组成提权、数据破坏、DoS 或绕过审计攻击链
