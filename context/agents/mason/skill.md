# 后端开发速查

## 【工具选择】

| 目的 | 使用工具 | 使用时机 | 不要用于 |
|------|---------|---------|---------|
| 确认目录结构 | `list_files` | 首次接触或不确定路径时 | 已知路径后重复列出 |
| 快速了解文件结构 | `analysis_files` | 文件 >100 行只需知道函数/类/类型/导出 | 需要复制代码片段时 |
| 定位函数或模式 | `search_files` | 知道关键词但不知路径 | 关键词太泛或替代读取目标文件 |
| 读取实现细节 | `read_files` | 已知目标文件或 analysis 后需要具体代码 | 首次探索大型未知文件 |
| 读取语言技能 | `read_contexts` | 识别语言后读取 `skills/backend-*.md` | 读取项目代码或 agent 配置 |
| 查找技能路径 | `context_lists` / `search_contexts` | 不确定技能名或需要语言技能摘要时 | 替代任务和代码勘察 |
| 验证构建/启动/测试 | `run_command` | 验证阶段 | 探索性查看文件内容 |

## 【高风险判断】

| 遇到情况 | 正确做法 | 错误做法 |
|---------|---------|---------|
| 读取请求体、文件、消息或批量参数 | 设置大小/数量/深度/耗时上限并处理超限错误 | 按客户端声明或默认读取全部内容 |
| 登录、验证码、Token、敏感操作 | 同时考虑主体、来源、全局频率限制和时序差异 | 只按单一 IP 或单一账号计数 |
| 状态变更入口 | 强制方法/命令类型约束并校验防伪请求或等价凭据 | 允许可被静默触发的入口执行写操作 |
| 客户端提交角色、权限、状态或高权限字段 | 服务端字段白名单+授权范围校验+业务不变量保护 | 直接透传请求字段到模型或权限表 |
| 跳转、响应头、日志、错误信息含用户输入 | 过滤 CRLF/控制字符并编码输出 | 原样拼接到 header、Location 或日志 |
| 搜索、排序、字段名、LIKE、关联 ID 来自用户 | 使用白名单和转义/参数化 | 只参数化值但放任字段名或通配符 |
| 树、菜单、父子关系、依赖图、流程图 | 检查间接环路、深度和不存在引用 | 只检查直接自引用 |
| 创建前先查重再写入 | 依赖唯一约束/事务兜底并捕获冲突 | 只用 count/exist 检查唯一性 |
| 会话、日志、审计、缓存、临时文件长期增长 | 设计清理、轮转、保留期、失效或上限 | 只在读取时被动清理或永久缓存 |
| 循环内逐条查询数据库（N+1） | 批量 WHERE IN 或 JOIN 预加载 | 循环发 SQL 不检测性能影响 |
| 缓存无过期时间/无容量限制 | 设 TTL + 主动失效 + 容量上限 | 永久缓存或无限增长 |
| 深页 OFFSET 分页（>10000条） | Keyset/Cursor 分页或限制最大页数 | 不管数据量直接 OFFSET |
| 网络服务、后台任务、长连接或并发执行 | 检查生产入口、超时、资源限制、连接/缓存生命周期 | 用开发入口或单线程假设替代运行设计 |

## 【常见判断】

| 遇到情况 | 正确做法 | 错误做法 |
|---------|---------|---------|
| 任务要求新增接口 | 先搜同类接口实现，再按项目模式编写 | 从零设计接口风格 |
| `[Backend]` 无语言标签 | 扫描配置和目标文件识别语言，再读对应技能 | 默认选择熟悉语言 |
| 多语言仓库 | 按目标文件、入口和任务描述确定本次语言 | 按仓库最大语言处理所有任务 |
| 任务涉及模板视图数据 | 处理后端查询、数据组装和模板变量注入，模板结构/样式/交互交给 emma | 顺手重写前端布局 |
| 任务未写安全要求但有外部输入/数据写入 | 落实校验、参数化、权限或事务等适用项 | 只做快乐路径 |
| 第三方 API 或外部服务对接 | 覆盖鉴权失败、超时/取消、限流、重试幂等、非 JSON、业务错误码和敏感日志 | 只实现成功响应 |
| SQL、报表或批量数据处理 | 覆盖 NULL、重复、分页/批处理、索引/全表扫描、动态字段白名单、事务回滚和历史数据兼容 | 只用小样本正常数据验证 |
| 任务使用模型/工具输出 | 校验来源、格式、权限和敏感信息后落地 | 直接执行或保存输出 |
| 发现设计缺少明显后端安全边界 | 保守处理可确定部分并报告缺口 | 自行扩成完整安全重构 |
| 发现设计缺少性能或运行性边界 | 落实当前任务可确定的上限/清理/错误处理，并报告缺口 | 假设低并发、小数据或开发环境永远成立 |
| 错误分支、认证校验失败、中间件拦截、外部调用或状态变更 | 添加调试级别日志（含请求标识、操作路径、失败原因）；请求追踪设计存在时确保 ID 传递 | 所有行都加日志 或 只记录成功路径 或 日志含密码/Token |
| 发现文档与实现冲突 | 以代码事实安全落地并报告文档同步点 | 按过期文档强改或忽略差异 |
| 不确定包管理器或测试命令 | 查 lock 文件、脚本、README、CI 配置 | 固定使用常见命令 |
| 需要启动服务验证 | 按 AGENTS.md 服务管理章节命令启动，阻塞式命令用 `run_command(background=true)` | 直接前台运行阻塞式启动命令 |
| 验证完毕 | `run_command(stop_background=PID)` 清理后台进程 | 不停止服务就结束 |
| 同技术栈文件中发现的明显后端缺陷 | 一并修复并在总结中说明 | 修改其他语言或前端文件 |
| 跨技术栈发现的问题 | 记录到总结的"额外发现"章节 | 顺手修改前端模板/CSS/JS |
| 不确定字段命名 | 搜索项目中同类字段命名惯例 | 用个人习惯命名 |
